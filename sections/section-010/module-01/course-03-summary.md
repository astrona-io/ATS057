# Summary

Cluster Mesh connects supported workload networking across clusters while their Kubernetes control planes remain independent. Unique cluster identity, compatible addressing and reachable data paths are prerequisites.

State exchange, network transport and policy trust must be assessed separately. Mesh membership does not replicate every Kubernetes object or application database, and stronger reachability needs deliberate restrictions and failure-domain planning.
